# Purpose

1. We are building a tool for terminal windows that allows browsing, tagging and preview of samples
2. It will use the existing p6-tool as a base, all code can be copied in, the original p6-tool will be archived
3. We will add support for both p6 and circuit tracks to allow groups of samples to be sent to these devices, however that is a stretch goal
4. We will make the configuration device agnostic so that initially it allows samples to be grouped


# Device Support

- Roland p6
- Novation Circuit Tracks

# Documentation

I have added docs/reference to allow agents to read the documentation for these devices
